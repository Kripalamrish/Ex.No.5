

# EXP 5: Comparing Prompting Techniques Through Engineering Problem-Solving Scenarios

# Aim:
To compare different prompting techniques and evaluate their effectiveness in solving real-world engineering problems by using a problem selected from a student's 3rd-year or final-year project work. 

# Procedure:

1.Select a real engineering problem from a 3rd-year or final-year project.

2.Write a simple naïve/base prompt describing the selected problem.

3.Enter the prompt into ChatGPT and record the generated response.

4.Rewrite the same problem using at least four different prompting techniques such as Query Decomposition, Decision Making, Role Prompting, Constraint-Based Prompting, and Answer Engineering.

5.Enter each improved prompt into ChatGPT and record the generated responses.

6.Compare all responses based on quality, accuracy, relevance, clarity, completeness, and feasibility.

7.Prepare a comparison table and give suitable scores for each prompting technique.

8.Analyze which prompting technique gives the best solution for the selected engineering problem.

9.Prepare a refined final prompt using the best-performing prompting techniques.

10.Validate the final AI-generated solution with engineering requirements and record the observations, result, and conclusion.


### Project Title:
AI-Based Network Intrusion Detection System

### Problem Statement:
In a computer network, malicious activities such as DoS attacks, port scanning, brute-force attacks and unauthorized access can threaten system security. The objective of this project is to develop a machine-learning-based system that can analyze network traffic and identify whether the traffic is normal or malicious.

### Base Prompt:
How can I detect network attacks using machine learning?

### Prompting Technique 1 – Straightforward / Basic Prompt:

Suggest a suitable machine learning approach for detecting network attacks. Explain the dataset, preprocessing, important network features, suitable classification algorithms, training process and evaluation metrics.

### Prompting Technique 2 – Role/Persona Prompt:

Act as a cybersecurity and machine learning engineer. Design a practical approach for an AI-based network intrusion detection system for a final-year CSE project. Explain the dataset, preprocessing, feature engineering, model selection, training, testing, evaluation metrics and deployment. Keep the solution feasible for a college-level implementation.

### Observation:

The role-based prompt produces a more practical and project-oriented answer because the AI is instructed to respond from the perspective of an expert and consider college-level feasibility.

### Prompting Technique 3 – Query Decomposition:

Solve the network intrusion detection problem by breaking it into the following steps:

Identify suitable datasets.
Identify preprocessing requirements.
Select important network features.
Compare suitable machine learning algorithms.
Design the training and testing process.
Select evaluation metrics.
Explain how the final system can be deployed.
Finally, combine all the steps into one complete solution suitable for a final-year CSE project.

### Output:

<img width="772" height="821" alt="image" src="https://github.com/user-attachments/assets/e5dd3a97-dfba-4f75-ab7e-e116de29c328" />

### Observation:

Query decomposition produces a highly organized response. The complex engineering problem is divided into smaller tasks, making the solution easier to understand and implement.

### Prompting Technique 4 – Decision-Making Prompt:

For an AI-based network intrusion detection system, choose the most suitable machine learning algorithm from Decision Tree, Random Forest, SVM, K-Nearest Neighbours and Neural Network. Consider accuracy, computational complexity, interpretability, ability to handle multiple features and suitability for a final-year CSE project. Select one algorithm and justify the decision. Also mention why the other algorithms were not selected as the primary model.

### Obsrvation:

The decision-making prompt does not simply ask for a solution. It makes the AI compare alternatives and select the most appropriate option based on defined criteria. Therefore, the response is more useful for making an engineering design decision.


### Prompting Technique 5 – Constraint-Based Prompt:

Design a network intrusion detection system using machine learning with the following constraints: it should be suitable for a final-year CSE project, use publicly available data, avoid requiring expensive hardware, provide measurable evaluation results, and be implementable using Python and common machine learning libraries. Explain the complete approach.

### Prompting Technique 6 – Answer Engineering:

Provide the solution in the following format:

Problem definition
Proposed architecture
Dataset
Data preprocessing
Feature selection
Machine learning model
Training process
Testing process
Evaluation metrics
Expected result
Use formal but simple technical language suitable for a final-year CSE project.
